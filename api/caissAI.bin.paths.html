caissAI.bin.paths module

Résolution des chemins runtime de caissAI.

Le programme n’écrit jamais dans le package installé : une réinstallation ou un uv tool upgrade remplacerait le contenu du package et effacerait les PGN traités et les journaux applicatifs.

Tous les emplacements suivent la même précédence : argument CLI > variable d'environnement > défaut utilisateur.

Variables reconnues :

CAISSAI_PGN Fichier PGN traité par défaut (équivaut à –pgn) CAISSAI_DATA_DIR Dossier data/ (input/ et output/), hors du package installé CAISSAI_LOG_DIR Dossier des journaux applicatifs CAISSAI_MAIA2_DIR Dossier des poids Maia2 (blitz_model.pt)

config/lichess_eco.parquet reste packagé : c’est une donnée de référence livrée avec le code, jamais écrite à l’exécution, donc hors du périmètre de ce module (voir utils.get_folder_path).

caissAI.bin.paths.resolve_maia2_dir(cli_value=None)[source]

Résout le dossier des poids Maia2 (blitz_model.pt).

maia2.model.from_pretrained télécharge ses poids dans save_root, dont le défaut ./maia2_models est relatif au répertoire courant. Sans cette résolution explicite, un lancement depuis un autre dossier provoque un nouveau téléchargement de plusieurs centaines de Mo.

Le défaut reproduit le comportement de maia2 (./maia2_models) pour rester compatible avec les installations existantes.

Parameters:

cli_value (str | None) – Valeur passée en argument CLI, ou None.

Return type:

Path

Returns:

Chemin résolu (peut ne pas encore exister ; maia2 le crée au besoin).

Examples

>>> resolve_maia2_dir().name
'maia2_models'
caissAI.bin.paths.resolve_path(cli_value, env_var, default)[source]

Résout un chemin selon la précédence CLI > environnement > défaut.

S’applique indifféremment à un dossier ou à un fichier : la fonction ne fait que choisir une valeur et normaliser ~, sans rien créer ni vérifier l’existence.

Parameters:

  • cli_value (str | None) – Valeur passée en argument CLI (prioritaire), ou None.

  • env_var (str) – Nom de la variable d’environnement à consulter ensuite.

  • default (Path) – Valeur de repli si ni l’un ni l’autre n’est renseigné.

Return type:

Path

Returns:

Chemin résolu, avec ~ développé.

Examples

>>> resolve_path("/tmp/cli", "UNSET_VAR_XYZ", Path("/tmp/def")).name
'cli'
>>> resolve_path(None, "UNSET_VAR_XYZ", Path("/tmp/def")).name
'def'
>>> resolve_path("", "UNSET_VAR_XYZ", Path("/tmp/def")).name
'def'
