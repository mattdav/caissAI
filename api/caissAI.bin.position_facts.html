caissAI.bin.position_facts module

Faits de position calculés localement (fonctions pures, FEN et coups en entrée).

Chaque fonction reçoit une FEN (et éventuellement un coup en UCI) et renvoie un dictionnaire sérialisable en JSON. Aucune ne fait appel à un moteur.

caissAI.bin.position_facts.lost_support(fen, move_uci)[source]

Liste les pièces qui perdent un défenseur ou une case de retraite.

Seules les pièces du camp qui joue sont examinées.

Parameters:

  • fen (str) – Position avant le coup.

  • move_uci (str) – Coup joué (UCI).

Returns:

{“piece”, “case”, “defenseur”} (le défenseur est désigné par sa case avant le coup) ; retraites_perdues : {“piece”, “case”, “retraite”}.

Return type:

dict[str, list[dict[str, str]]]

Examples

>>> fen = "r1bq1rk1/pp3ppp/2n5/2bp4/8/1QN1PN2/PP2BPPP/R3K2R b KQ - 1 10"
>>> {"piece": "cavalier", "case": "c6", "defenseur": "b7"} in lost_support(
...     fen, "b7b6"
... )["defenseurs_perdus"]
True
caissAI.bin.position_facts.pawn_structure(fen)[source]

Décrit la structure de pions de chaque camp.

Parameters:

fen (str) – Position à analyser.

Returns:

pions isoles, doubles, arrieres, passes (noms de cases), nombre d’ilots, colonnes colonnes_ouvertes (sans pion) et colonnes_semi_ouvertes (sans pion du camp, avec un pion adverse), et cases_trouees du camp.

Return type:

dict[str, dict[str, Any]]

Examples

>>> fen = "r1bq1rk1/pp3ppp/2n5/2bp4/8/2N1PN2/PP2BPPP/R2QK2R b KQ - 0 9"
>>> pawn_structure(fen)["noirs"]["isoles"]
['d5']
>>> pawn_structure(fen)["noirs"]["colonnes_semi_ouvertes"]
['e']

caissAI.bin.position_facts.recapture_choice(fen_before, capture_uci)[source]

Détecte un choix de reprise après une prise adverse.

Parameters:

  • fen_before (str) – Position avant la prise de l’adversaire.

  • capture_uci (str) – La prise de l’adversaire (UCI).

Return type:

dict[str, Any] | None

Returns:

None si le coup n’est pas une prise ou s’il y a moins de deux reprises légales ; sinon {“case”, “reprises” (SAN), “pion_et_piece”}, où pion_et_piece vaut True si une reprise de pion et une reprise de pièce existent.

Examples

>>> start = "r1bq1rk1/pp2bppp/2n1pn2/2pp4/2PP4/2N1PN2/PP2BPPP/R1BQK2R w - - 0 8"
>>> recapture_choice(start, "c4d5") is not None
True
